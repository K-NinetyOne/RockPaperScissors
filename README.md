RockPaperScissors

The Odin Project: Browser based Rock Paper Scissors game written with Javascript.

This project will have the following steps

    This project intended to be a reworking of the earlier console based RockPaperScissors game.

    The logic to play 5 rounds was removed and user input replaced with eventListener buttons for each human choice

    Scores were displayed on screen in addition to an alert message upon the games completion

Project completed according to project specifications and working in browser console (Firefox and Chromium).
